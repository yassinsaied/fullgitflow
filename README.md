# Next.js GitFlow Demo

## Description

A simple Next.js application created to learn and demonstrate a professional GitFlow workflow with GitHub.

The project is intentionally simple. The main goal is to practice:

- Git branches
- GitFlow
- Feature branches
- Bug fixes
- Pull Requests
- Code reviews
- Merge strategies
- Branch protection
- Releases
- GitHub Actions

## Requirements

- Node.js >= 20
- npm >= 10
- Git
- GitHub account

Clone the repository:

git clone <repository-url>
